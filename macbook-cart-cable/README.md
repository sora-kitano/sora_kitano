# MacBook充電保管庫のケーブル整理パーツ

充電保管庫の **前面でケーブルの垂れ長さがバラバラになる問題** と **背面で余ったケーブルが垂れて絡まる問題** を、3Dプリント部品で解決するためのデータ一式です。保管庫に穴を開けたり既存部品を外したりはしないので、結束バンドを切ればいつでも元に戻せます。

![改善前と改善後](images/install_diagram.png)

## なぜバラバラになるのか

MagSafe 3ケーブルは2mあり、アダプタからMacBookまでの経路（背面→天井の配線トレイ→前面）より1m前後長くなります。前面の白いクリップはケーブルを **左右には** 押さえていますが、**前後方向には何も止めていない** ので、余った1mが前と後ろを行き来します。

- MacBookを取り出すとき、ケーブルごと手前に引き出される
- 戻すときに引き出した分は戻らないので、前面の輪の大きさがスロットごとに違ってくる
- 背面ではケーブルの余りに定位置がないので、垂れ下がって隣のケーブルと絡む

対策はこの仕組みの裏返しで、**(1) 前面のクリップの位置でケーブルを前後に固定する**、**(2) 余った分は背面に定位置を作ってまとめる**、の2つです。

背面だけで固定しても、背面と前面の間のトレイ内にたるみがあれば前面の長さは決まりません。前面の見た目を決めているのはクリップから先の長さなので、固定点は前面クリップのところに置くのがいちばん確実です。

## 部品

![部品一覧](images/parts_overview.png)

| # | 部品 | ファイル | 用途 |
|---|---|---|---|
| ① | ケーブル径ゲージ | `stl/cable_gauge.stl` | ケーブルの太さを測ってサイズを決める。最初に1枚だけ印刷 |
| ② | ストッパー半割 | `stl/d<径>/stopper_half_d<径>.stl` | 同じ部品2個でケーブルを挟み、結束バンドで締める。既存クリップの前と後ろに1組ずつ付ける |
| ③ | 余長ホルダー | `stl/d<径>/slack_holder_d<径>.stl` | 背面で余ったケーブルを上下のフックに輪にして掛ける |

②と③は、ケーブルの太さ（3.4〜5.4mm、0.2mm刻み）ごとにフォルダを分けてあります。

![余長ホルダーの使用例](images/holder_3d.png)

## 進め方

### 1. ケーブルの太さを決める（ゲージ）

Apple公式のケーブル外径は見つからず、写真から推定すると4〜5mm前後です。推測で決めず、実物で確かめます。

1. `cable_gauge.stl` を印刷する（30分弱）
2. ケーブルを横からスロットに押し込み、**力を入れずにスッと入る一番細いスロット** の数字を読む
3. その数字のフォルダ（例：4.4なら `stl/d4.4/`）の②③を使う。2つで迷ったら細い方にする

ゲージは同じプリンタで刷るので、プリンタごとの穴の縮み（0.1〜0.2mmほど）も込みで測れます。

### 2. 2〜3スロット分だけ試作する

いきなり全部刷らず、まず **ストッパー半割4個とホルダー1個（1スロット分）× 2〜3スロット** だけ作って取り付け、1〜2週間ほど実際に使ってみてください。確認したい点は次のとおりです。

- ストッパーが既存クリップの穴をすり抜けないか（ストッパーの断面は17×14mm）
- 結束バンドで締めたとき、ケーブルを手で引いても滑らないか
- ホルダーに余りが収まりきるか（収納量の目安は下の表）

### 3. 取り付け（前面）

1. MacBookを収納し、MagSafeを挿す
2. 庫内側（トレイ側）からケーブルを引いて、**MagSafeが無理なく届き、少しだけたるむ長さ** に前面の垂れをそろえる。全スロットでこの長さをそろえると見た目が揃う
3. 白いクリップの **すぐ後ろ（庫内側）** で、半割2個でケーブルを挟む。片方を裏返して合わせるとピンと穴がはまる
4. 中央の溝に結束バンドを1周させ、**ケーブルを手で引いても動かなくなったところで止める**（それ以上は締めない）。余りを切り、ヘッドは横か上に向ける
5. 同じものをクリップの **すぐ前** にも付ける（トレイの縁までの余裕が少なければ、縁から少しはみ出しても機能は同じ）

前後の2組でクリップを挟む形になり、ケーブルは前にも後ろにも動かなくなります。最低限の対策なら後ろの1組だけでも「取り出すときに引き出される」問題は止まりますが、背面の重みでケーブルが奥に引き込まれることがあるので、2組を推奨します。

### 4. 取り付け（背面）

![余長ホルダーの使い方](images/holder_usage.png)

1. アダプタから天板の隙間へ上がっていくケーブルの途中にホルダーを縦向きに当て、**下の固定クリップ** にアダプタ側のケーブルを上から押し込む
2. 余ったケーブルで輪を作り、**上下のフックに順番に引っ掛けていく**。ホルダー本体を回して巻くとケーブルがねじれるので、回さずに輪を掛ける
3. 最後に **上の固定クリップ** に押し込み、上（天板の隙間）へ出す
4. 揺れるのが気になる場合は、中央のスリットに結束バンドや面ファスナーを通して近くのフレームや配線に留める

余りの長さはスロットごとに違うので、周回数を変えて吸収します。

| ケーブル径 | 1周の長さ | 最大周回数 | 収納できる長さ |
|---|---|---|---|
| 3.6mm | 約20cm | 8周 | 約1.6m |
| 4.0mm | 約20cm | 7周 | 約1.4m |
| 4.4mm | 約20cm | 6周 | 約1.2m |
| 5.0mm | 約20cm | 6周 | 約1.2m |

フック部分でのケーブルの曲げ半径は約9〜10mmで、無理に折り曲げることはありません。

## 印刷設定

| 項目 | 推奨 |
|---|---|
| 材料 | **PETG**（PLAは試作なら可） |
| ノズル / レイヤー | 0.4mm / 0.2mm |
| 壁（ウォール） | 3〜4周 |
| インフィル | ホルダー 20%、ストッパー 40%以上 |
| サポート | 不要 |
| 向き | STLのまま（ストッパーは割り面が上、ホルダーはプレートが下） |
| 色 | 白かライトグレーにすると保管庫になじむ |

PETGを推奨する理由は熱です。37台分のアダプタが同時に充電すると庫内は暖かくなります。PLAは60℃前後で柔らかくなり始め、もっと低い温度でも、結束バンドで締め続けている部品は時間とともに少しずつ変形してゆるみやすくなります（クリープ）。PETGは耐熱性に一段余裕があります。

## 必要数（37台の場合）

| 部品 | 1スロットあたり | 37台分 |
|---|---|---|
| ① ケーブル径ゲージ | — | 1枚 |
| ② ストッパー半割 | 4個（2組） | 148個＋予備 |
| ③ 余長ホルダー | 1個 | 37個 |
| 結束バンド（幅2.5〜3.6mm、長さ100mm程度） | 2本（ホルダー固定にも使うなら＋1〜2本） | 74本〜 |

材料の目安は、ストッパー半割が1個あたり約1.5g、ホルダーが1個あたり約10g（中実で約18g）で、合計0.6kg前後、PETG 1kgスプール1巻で足りる見込みです。印刷時間はプリンタ次第ですが、合計で数十時間規模になるので、何日かに分けて刷る前提で考えてください。正確な重さと時間はスライサーで確認してください。

## 注意

- 学校の備品なので、取り付け前に保管庫の管理担当の先生（情報担当など）に確認してください。穴あけや既存部品の取り外しはしないので、元に戻すのは簡単です
- 結束バンドを締めすぎるとケーブル内部を傷める可能性があります。「手で引いて動かない」で止めてください
- ホルダーやケーブルの束をアダプタに密着させないでください（放熱の妨げになります）
- 3Dプリント樹脂（PLA/PETG）は難燃材ではありません。電源タップの差し込み口まわりには置かないでください

## 寸法を変えたいとき

形状はすべて `cad/generate.py` の数値から作っています。

```bash
pip install manifold3d numpy matplotlib
python3 cad/generate.py          # stl/ を作り直す
python3 cad/render_previews.py   # images/ を作り直す（任意）
```

よく触りそうな数値は次のとおりです。

- 既存クリップの穴がストッパーより大きかった → `STOPPER` の `W`（幅）と `H`（半割の高さ）を大きくする
- ストッパーが滑る / 締まりすぎる → `STOPPER` の `rib_h`（内側リブの高さ、初期値0.4mm）を増やす / 減らす
- ホルダーに余りが収まらない → `HOLDER` の `D`（フック間隔、初期値70mm）か `hh`（フック高さ）を大きくする
- 別の太さのケーブルを使う → `CABLE_SIZES` に追加する

## 3Dプリンタを使わない場合

背面だけなら、余りを20cmほどの長さでジグザグに折りたたんで面ファスナー（マジックテープ）の結束バンドで留める方法でも整理できます。ただし前面の「引き出される」問題は、前面クリップの位置でケーブルを固定しない限り解決しないので、②のストッパーに相当するもの（たとえば結束バンドをケーブルに巻いてクリップに引っかかる“こぶ”を作るなど）は別途必要です。
