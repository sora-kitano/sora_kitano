# 組版計画（A4横 297×210mm）

- 外周余白：上10・下9.5・左右11mm → 版面 275×190.5mm。
- 上部の帯（y 10–42mm, 高さ32mm）：左にタイトル28pt明朝＋副題（幅約150mm）。右（右端揃え、幅112mm）に対象地域・氏名（1行）とリード9pt（4行）。
- 3段（y 48–189.5mm）：左85mm／中97mm／右81mm、段間6mm（比率31:35:30）。
  - 右段は「1行24字以上（9pt）」と縦軸の溝（約3.4mm）を両立させるため、指定の28%より広げた。
  - 中段は未来の一文（13pt明朝）を「、」で2行に収めるため97mm（21字×13pt≒96.3mm）。
- 左段：見出し → 第1・第2段落 → 図A（幅いっぱい・高さ約30mm）→ 第3段落 → 図C（約16mm）。
- 中段：見出し → 未来の一文 → 図B（幅いっぱい・高さ約43mm）→ 本文3段落。
- 右段：見出し → 左端に図Dの縦軸（スクリプトで節目の位置を実測して描画）、①②は2026年度、③は2030年代の下。2045年・2050年は段の下端に寄せ、時間の長さを余白で示す。アイコン（10mm角）は小見出しの左に回り込み。
- 出典：最下部、全幅、6.5ptグレー2行。
- 図A・B・C・Dとアイコンはすべてインライン SVG（pt単位の viewBox）を、HTML内のスクリプトで第5章のデータから生成する。

## 組んだ後の調整（最終値）

- 帯の高さを30mmに、段の開始を44.5mmに上げた（左段・中段のあふれ解消のため）。段の高さ145mm。
- 右段のアイコンは「回り込み」をやめ、アイコン＋小見出しの行の下に全幅の本文を置いた（回り込むと1行が約20字になり、24字の下限を割るため）。アイコンは10mm角。
- Google Fonts 版 Shippori Mincho には palt が無いため、タイトルは同フォントのグリフ外形から詰め量を計算して手で詰めた。
- `text-rendering: geometricPrecision` を指定。小さい文字で数字の送り幅がピクセルに丸められ、PDFで「7 0.4 ％」のように字間が乱れるのを防ぐ。
